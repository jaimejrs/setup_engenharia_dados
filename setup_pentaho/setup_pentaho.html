1 Instalação automática (script único)

Para quem só quer instalar tudo de uma vez, sem seguir os passos manuais um a um: copie o script do seu sistema operacional abaixo, cole em um terminal e pressione Enter. Ele faz sozinho tudo o que está descrito nas seções 2 a 6 deste guia: verifica/instala o Java, baixa o PDI, extrai os arquivos e confirma que ficou tudo certo.

Como abrir o terminal Clique no menu Iniciar, digite PowerShell, clique em "Windows PowerShell" (não precisa ser como administrador).

Script completo (copie tudo abaixo)

<#
    Instalação automática do PDI (Pentaho Data Integration) Community Edition
    Cole este script inteiro em uma janela do PowerShell e pressione Enter.
#>

$ErrorActionPreference = "Stop"

function Write-Step($msg) {
    Write-Host ""
    Write-Host "==> $msg" -ForegroundColor Cyan
}

# --- 1. Verificar / instalar Java (JDK 17) ---------------------------------
Write-Step "Verificando Java..."

$jdkBase = "C:\Program Files\Eclipse Adoptium"
$jdkFolder = Get-ChildItem $jdkBase -Directory -ErrorAction SilentlyContinue |
             Where-Object { $_.Name -match "^jdk-1[1-8]" } |
             Select-Object -First 1 -ExpandProperty FullName

if (-not $jdkFolder) {
    Write-Host "Java (JDK 11-18) não encontrado. Instalando Eclipse Temurin 17 via winget..."
    winget install --id EclipseAdoptium.Temurin.17.JDK -e --accept-package-agreements --accept-source-agreements --silent
    $jdkFolder = Get-ChildItem $jdkBase -Directory -ErrorAction SilentlyContinue |
                 Where-Object { $_.Name -match "^jdk-17" } |
                 Select-Object -First 1 -ExpandProperty FullName
    if (-not $jdkFolder) {
        throw "Falha ao instalar o Java. Instale manualmente em https://adoptium.net/ e rode este script novamente."
    }
} else {
    Write-Host "Java já instalado em: $jdkFolder"
}

# Atualiza PATH/JAVA_HOME nesta sessão e de forma permanente para o usuário
$env:Path = [System.Environment]::GetEnvironmentVariable("Path", "Machine") + ";" +
            [System.Environment]::GetEnvironmentVariable("Path", "User")
$env:JAVA_HOME = $jdkFolder
[System.Environment]::SetEnvironmentVariable("JAVA_HOME", $jdkFolder, "User")

Write-Host (& "$jdkFolder\bin\java.exe" -version 2>&1 | Select-Object -First 1)

# --- 2. Baixar o PDI Community Edition --------------------------------------
Write-Step "Baixando o PDI Community Edition 9.4.0.0 (~385 MB)..."

$pdiUrl  = "https://github.com/ambientelivre/legacy-pentaho-ce/releases/download/pdi-ce-9.4.0.0-343/pdi-ce-9.4.0.0-343.zip"
$zipPath = "$env:USERPROFILE\Downloads\pdi-ce-9.4.0.0-343.zip"
$installDir = "C:\pentaho"

if (Test-Path "$installDir\data-integration\Spoon.bat") {
    Write-Host "PDI já parece estar instalado em $installDir. Pulando download."
} else {
    if (-not (Test-Path $zipPath)) {
        Invoke-WebRequest -Uri $pdiUrl -OutFile $zipPath
    } else {
        Write-Host "Arquivo já baixado em $zipPath. Pulando download."
    }

    # --- 3. Extrair --------------------------------------------------------
    Write-Step "Extraindo arquivos para $installDir ..."
    New-Item -ItemType Directory -Force -Path $installDir | Out-Null
    Expand-Archive -Path $zipPath -DestinationPath $installDir -Force
}

# --- 4. Confirmar instalação -------------------------------------------------
Write-Step "Verificando instalação..."
$spoonPath = "$installDir\data-integration\Spoon.bat"
if (-not (Test-Path $spoonPath)) {
    throw "Algo deu errado: $spoonPath não foi encontrado."
}

Write-Host ""
Write-Host "Instalação concluída com sucesso!" -ForegroundColor Green
Write-Host "Para abrir o PDI (Spoon), execute:"
Write-Host "  cd `"$installDir\data-integration`"; .\Spoon.bat" -ForegroundColor Yellow

# --- 5. Perguntar se deseja abrir o Spoon agora ------------------------------
$resp = Read-Host "Deseja abrir o Spoon agora? (S/N)"
if ($resp -match "^[sSyY]") {
    Start-Process -FilePath $spoonPath -WorkingDirectory "$installDir\data-integration"
    Write-Host "Abrindo o Spoon... aguarde alguns segundos até a janela aparecer."
}
⚠ Se aparecer erro sobre "execução de scripts desabilitada" Esse aviso só ocorre ao executar um arquivo .ps1 salvo no disco, não ao colar o texto direto no terminal. Colando o script e pressionando Enter, ele roda linha a linha sem precisar alterar nenhuma política de execução do PowerShell.
Como abrir o terminal Atalho Ctrl+Alt+T na maioria das distros, ou procure "Terminal" no menu de aplicativos. Testado com foco em Ubuntu/Debian (também detecta Fedora/dnf e Arch/pacman).

Script completo (copie tudo abaixo)

#!/usr/bin/env bash
# Instalação automática do PDI (Pentaho Data Integration) Community Edition — Linux
# Cole este script inteiro em um terminal bash e pressione Enter,
# ou salve como arquivo e rode: bash instalar_pdi_linux.sh

set -e

step() { echo ""; echo "==> $1"; }

INSTALL_DIR="$HOME/pentaho"
ZIP_PATH="$HOME/Downloads/pdi-ce-9.4.0.0-343.zip"
PDI_URL="https://github.com/ambientelivre/legacy-pentaho-ce/releases/download/pdi-ce-9.4.0.0-343/pdi-ce-9.4.0.0-343.zip"

# --- 1. Verificar / instalar Java (11-18) -----------------------------------
step "Verificando Java..."

java_ok=false
if command -v java >/dev/null 2>&1; then
    ver=$(java -version 2>&1 | head -1 | grep -oE '"[0-9]+' | tr -d '"')
    if [ "$ver" -ge 11 ] 2>/dev/null && [ "$ver" -le 18 ] 2>/dev/null; then
        java_ok=true
        echo "Java $ver já instalado."
    fi
fi

if [ "$java_ok" = false ]; then
    if command -v apt >/dev/null 2>&1; then
        echo "Instalando OpenJDK 17 via apt (será pedida a senha do sudo)..."
        sudo apt update
        sudo apt install -y openjdk-17-jdk
    elif command -v dnf >/dev/null 2>&1; then
        echo "Instalando OpenJDK 17 via dnf (será pedida a senha do sudo)..."
        sudo dnf install -y java-17-openjdk
    elif command -v pacman >/dev/null 2>&1; then
        echo "Instalando OpenJDK 17 via pacman (será pedida a senha do sudo)..."
        sudo pacman -Sy --noconfirm jdk17-openjdk
    else
        echo "Não foi possível detectar apt/dnf/pacman. Instale manualmente um JDK 11-18 (64 bits) e rode este script novamente."
        exit 1
    fi
fi

# --- 2. Dependência gráfica opcional (libwebkitgtk) -------------------------
step "Verificando dependência gráfica (libwebkitgtk)..."
if command -v apt >/dev/null 2>&1; then
    sudo apt install -y libwebkitgtk-1.0-0 2>/dev/null \
        || echo "Aviso: libwebkitgtk-1.0-0 não disponível nesta versão do sistema. O Spoon deve abrir normalmente, mas alguns recursos que usam navegador embutido (ex.: Marketplace) podem não funcionar. Isso é uma limitação conhecida do PDI 9.x em distros mais novas."
fi

# --- 3. Baixar o PDI Community Edition ---------------------------------------
step "Baixando o PDI Community Edition 9.4.0.0 (~385 MB)..."
mkdir -p "$HOME/Downloads"

if [ -f "$INSTALL_DIR/data-integration/spoon.sh" ]; then
    echo "PDI já parece estar instalado em $INSTALL_DIR. Pulando download."
else
    if [ ! -f "$ZIP_PATH" ]; then
        if command -v curl >/dev/null 2>&1; then
            curl -L -o "$ZIP_PATH" "$PDI_URL"
        elif command -v wget >/dev/null 2>&1; then
            wget -O "$ZIP_PATH" "$PDI_URL"
        else
            echo "Nem curl nem wget encontrados. Instale um dos dois e rode o script novamente."
            exit 1
        fi
    else
        echo "Arquivo já baixado em $ZIP_PATH. Pulando download."
    fi

    # --- 4. Extrair ----------------------------------------------------------
    step "Extraindo arquivos para $INSTALL_DIR ..."
    mkdir -p "$INSTALL_DIR"
    if ! command -v unzip >/dev/null 2>&1; then
        echo "Comando 'unzip' não encontrado. Instalando..."
        if command -v apt >/dev/null 2>&1; then sudo apt install -y unzip; fi
    fi
    unzip -o -q "$ZIP_PATH" -d "$INSTALL_DIR"
fi

chmod +x "$INSTALL_DIR/data-integration/"*.sh 2>/dev/null || true

# --- 5. Confirmar instalação --------------------------------------------------
step "Verificando instalação..."
SPOON_PATH="$INSTALL_DIR/data-integration/spoon.sh"
if [ ! -f "$SPOON_PATH" ]; then
    echo "Algo deu errado: $SPOON_PATH não foi encontrado."
    exit 1
fi

echo ""
echo "Instalação concluída com sucesso!"
echo "Para abrir o PDI (Spoon), execute:"
echo "  cd \"$INSTALL_DIR/data-integration\" && ./spoon.sh"

# --- 6. Perguntar se deseja abrir o Spoon agora -------------------------------
read -r -p "Deseja abrir o Spoon agora? (s/N) " resp
if [[ "$resp" =~ ^[sSyY] ]]; then
    (cd "$INSTALL_DIR/data-integration" && ./spoon.sh &)
    echo "Abrindo o Spoon... aguarde alguns segundos até a janela aparecer."
fi
⚠ Sobre a interface gráfica (libwebkitgtk) O PDI 9.x usa um componente antigo (GTK2/WebKitGTK 1.0) que não existe mais nos repositórios de distros recentes (Ubuntu 18.04+, por exemplo). O script tenta instalar essa dependência e, se não conseguir, apenas avisa e continua — o Spoon normalmente abre do mesmo jeito, só alguns recursos que dependem de navegador embutido (como o painel Marketplace) podem não funcionar. Isso é uma limitação conhecida da versão 9.4, não um erro do script.
Como abrir o terminal Abra o Terminal (Spotlight: Cmd+Espaço, digite "Terminal"). O script usa o Homebrew para instalar o Java — se ele ainda não estiver instalado, o script vai avisar e parar, mostrando o comando oficial de instalação do Homebrew.

Script completo (copie tudo abaixo)

#!/usr/bin/env bash
# Instalação automática do PDI (Pentaho Data Integration) Community Edition — macOS
# Cole este script inteiro em um terminal (Terminal.app / iTerm) e pressione Enter,
# ou salve como arquivo e rode: bash instalar_pdi_macos.sh

set -e

step() { echo ""; echo "==> $1"; }

INSTALL_DIR="$HOME/pentaho"
ZIP_PATH="$HOME/Downloads/pdi-ce-9.4.0.0-343.zip"
PDI_URL="https://github.com/ambientelivre/legacy-pentaho-ce/releases/download/pdi-ce-9.4.0.0-343/pdi-ce-9.4.0.0-343.zip"

# --- 1. Verificar / instalar Java (11-18) -----------------------------------
step "Verificando Java..."

java_ok=false
if command -v java >/dev/null 2>&1; then
    ver=$(java -version 2>&1 | head -1 | grep -oE '"[0-9]+' | tr -d '"')
    if [ "$ver" -ge 11 ] 2>/dev/null && [ "$ver" -le 18 ] 2>/dev/null; then
        java_ok=true
        echo "Java $ver já instalado."
    fi
fi

if [ "$java_ok" = false ]; then
    if command -v brew >/dev/null 2>&1; then
        echo "Instalando OpenJDK 17 via Homebrew..."
        brew install openjdk@17
        # Disponibiliza o 'java' no PATH desta sessão
        BREW_PREFIX=$(brew --prefix openjdk@17)
        export PATH="$BREW_PREFIX/bin:$PATH"
        export JAVA_HOME="$BREW_PREFIX"
        # link para o sistema encontrar via /usr/libexec/java_home (opcional, requer sudo)
        sudo ln -sfn "$BREW_PREFIX/libexec/openjdk.jdk" \
            "/Library/Java/JavaVirtualMachines/openjdk-17.jdk" 2>/dev/null || true
    else
        echo "Homebrew não encontrado. Instale o Homebrew primeiro executando:"
        echo '  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"'
        echo "Depois rode este script novamente."
        exit 1
    fi
fi

# --- 2. Baixar o PDI Community Edition ---------------------------------------
step "Baixando o PDI Community Edition 9.4.0.0 (~385 MB)..."
mkdir -p "$HOME/Downloads"

if [ -f "$INSTALL_DIR/data-integration/spoon.sh" ]; then
    echo "PDI já parece estar instalado em $INSTALL_DIR. Pulando download."
else
    if [ ! -f "$ZIP_PATH" ]; then
        curl -L -o "$ZIP_PATH" "$PDI_URL"
    else
        echo "Arquivo já baixado em $ZIP_PATH. Pulando download."
    fi

    # --- 3. Extrair ----------------------------------------------------------
    step "Extraindo arquivos para $INSTALL_DIR ..."
    mkdir -p "$INSTALL_DIR"
    unzip -o -q "$ZIP_PATH" -d "$INSTALL_DIR"
fi

chmod +x "$INSTALL_DIR/data-integration/"*.sh 2>/dev/null || true

# Remove o atributo de quarentena do macOS (evita bloqueio do Gatekeeper)
xattr -dr com.apple.quarantine "$INSTALL_DIR/data-integration" 2>/dev/null || true

# --- 4. Confirmar instalação ---------------------------------------------------
step "Verificando instalação..."
SPOON_PATH="$INSTALL_DIR/data-integration/spoon.sh"
if [ ! -f "$SPOON_PATH" ]; then
    echo "Algo deu errado: $SPOON_PATH não foi encontrado."
    exit 1
fi

echo ""
echo "Instalação concluída com sucesso!"
echo "Para abrir o PDI (Spoon), execute:"
echo "  cd \"$INSTALL_DIR/data-integration\" && ./spoon.sh"
echo "(Também há um app nativo em: $INSTALL_DIR/data-integration/Data Integration.app)"

# --- 5. Perguntar se deseja abrir o Spoon agora -------------------------------
read -r -p "Deseja abrir o Spoon agora? (s/N) " resp
if [[ "$resp" =~ ^[sSyY] ]]; then
    (cd "$INSTALL_DIR/data-integration" && ./spoon.sh &)
    echo "Abrindo o Spoon... aguarde alguns segundos até a janela aparecer."
fi
⚠ Gatekeeper / "app de desenvolvedor não identificado" O script já remove a quarentena dos arquivos baixados (xattr -dr com.apple.quarantine). Se ainda assim o macOS bloquear a execução, vá em Ajustes do Sistema → Privacidade e Segurança e autorize a abertura.
✔ O que o script faz, em ordem (nas três plataformas)
  1. Verifica se já existe um Java 11-18 instalado; se não houver, instala automaticamente (winget / apt / dnf / pacman / Homebrew, conforme o sistema)
  2. Configura as variáveis de ambiente necessárias
  3. Baixa o PDI Community Edition 9.4.0.0 (~385 MB)
  4. Extrai os arquivos na pasta do usuário (pentaho/data-integration)
  5. Confirma que a instalação ficou correta
  6. Pergunta se o aluno quer abrir o Spoon (interface gráfica) imediatamente
Os scripts são seguros para rodar mais de uma vez: detectam o que já está instalado/baixado e pulam essas etapas.

2 Requisitos do sistema

As seções abaixo explicam o mesmo processo manualmente, passo a passo — útil para entender o que o script faz ou para instalar sem o script.

ItemRequisito
Sistema operacionalWindows 10/11, Linux (Ubuntu/Debian, Fedora, Arch) ou macOS — sempre 64 bits
JavaJDK 64 bits, versão entre 11 e 18 (recomendado: 17)
Memória RAMMínimo 4 GB — recomendado 8 GB ou mais
Espaço em discoPelo menos 10 GB livres
InternetNecessária apenas durante o download (~385 MB)

As seções 3 a 7 abaixo usam exemplos de Windows (PowerShell). Os comandos equivalentes de Linux/macOS estão nos scripts da seção 1.

3 Instalar o Java (JDK)

O PDI é um aplicativo Java e não funciona sem um JDK instalado. Vamos usar o Eclipse Temurin (distribuição gratuita e confiável do OpenJDK).

Opção A — Via winget (recomendado, mais rápido)

Abra o PowerShell e execute:

winget install --id EclipseAdoptium.Temurin.17.JDK -e

Siga as instruções na tela e aceite os termos. A instalação é automática.

Opção B — Manual, pelo site

  1. Acesse adoptium.net
  2. Escolha Temurin 17 (LTS), sistema Windows, arquitetura x64, pacote JDK
  3. Baixe o instalador .msi e execute-o
  4. Durante a instalação, marque a opção "Set JAVA_HOME variable", se disponível
✔ Como conferir se o Java foi instalado Feche e abra um novo PowerShell (importante: precisa ser uma janela nova) e digite: 
java -version
Deve aparecer algo como openjdk version "17.0.x".

4 Baixar o PDI Community Edition

  1. Acesse o link de download direto (versão 9.4.0.0):
    github.com/ambientelivre/legacy-pentaho-ce (release pdi-ce-9.4.0.0-343)
  2. O download é um arquivo .zip de aproximadamente 385 MB — pode levar alguns minutos
  3. Salve o arquivo em Downloads (ou local de sua preferência)

Alternativa via PowerShell (baixa direto sem usar o navegador):

Invoke-WebRequest -Uri "https://github.com/ambientelivre/legacy-pentaho-ce/releases/download/pdi-ce-9.4.0.0-343/pdi-ce-9.4.0.0-343.zip" -OutFile "$env:USERPROFILE\Downloads\pdi-ce-9.4.0.0-343.zip"

5 Extrair os arquivos

  1. Crie uma pasta de destino, por exemplo C:\pentaho
  2. Clique com o botão direito no arquivo .zip baixado e escolha "Extrair tudo...", apontando para a pasta criada — ou use o PowerShell:
New-Item -ItemType Directory -Force -Path "C:\pentaho"
Expand-Archive -Path "$env:USERPROFILE\Downloads\pdi-ce-9.4.0.0-343.zip" -DestinationPath "C:\pentaho"

Ao final, você deve ter uma pasta C:\pentaho\data-integration contendo arquivos como Spoon.bat, Kitchen.bat, Pan.bat, entre outros.

6 Executar o PDI (Spoon)

O Spoon é a interface gráfica do PDI, usada para criar transformações e jobs de ETL.

  1. Navegue até a pasta C:\pentaho\data-integration
  2. Dê duplo clique em Spoon.bat
  3. Uma janela de console (preta) vai abrir rapidamente — é normal, ela inicializa o ambiente Java
  4. Após 15–30 segundos, a interface gráfica do Spoon deve abrir

Via PowerShell, o mesmo pode ser feito com:

cd "C:\pentaho\data-integration"
.\Spoon.bat

7 Verificar se está tudo certo

✔ Instalação correta se:
  • A janela do Spoon abre sem mensagens de erro
  • É possível criar uma nova transformação (menu Arquivo → Novo → Transformação)
  • É possível arrastar um passo (ex.: "Text file input") para a área de trabalho

8 Problemas comuns

"java não é reconhecido como comando"

O PATH do Windows só é atualizado em janelas do PowerShell/CMD abertas depois da instalação do Java. Feche a janela atual e abra uma nova.

O Spoon não abre / fecha sozinho

Verifique se o Java instalado é de 64 bits e está entre as versões 11 e 18. Rode java -version para confirmar.

Erro de memória (OutOfMemoryError)

Edite o arquivo Spoon.bat dentro da pasta data-integration e ajuste os valores de memória (parâmetros -Xms e -Xmx) próximos ao início do arquivo, aumentando-os se a máquina tiver RAM suficiente.

No Linux, o Spoon não abre (interface gráfica)

Instale a dependência libwebkitgtk-1.0-0 antes de rodar spoon.sh.
